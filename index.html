How to make a chart with Claude

  1. Pick a chart. Choose the type you want from the gallery below and note its name, for example "Bar, grouped" or "Slope".
  2. Open Claude with the GWI design system repo and ask for the chart type you picked, naming it as it appears in the gallery.
  3. Give Claude the data by pasting a table or attaching a CSV or Excel file. Also give the Source, the Base and the questions asked, each with its link. If anything is missing, Claude will ask.
  4. Check what Claude returns. You get one <gwi-chart> tag, like the example below. Check the numbers, title and subtitle, and ask Claude to change the data or wording until they are right. The look follows the design system. Ask for content changes, or for a styling override (see Inline styling below).
  5. Paste it into Webflow. On the report page, add a Code Embed and paste the whole tag. Do not add any other script.

Inline styling
CSS variables

Set any of these in the style attribute of the <gwi-chart> tag. Nothing changes if you set none. The Download image picture keeps the styling. Full list and defaults are in README.md.

  • --gwi-pink, --gwi-lime, --gwi-deep, --gwi-dlime, --gwi-grey Data colours
  • --gwi-ramp-1 to --gwi-ramp-9 Pink ramp for treemap, donut and heatmap
  • --gwi-ink, --gwi-ink-strong, --gwi-muted, --gwi-soft Text colours
  • --gwi-grid, --gwi-track, --gwi-axis Rules, bar tracks, axis lines
  • --gwi-radius, --gwi-bar-height Corner radius, bar thickness
  • --gwi-font, --gwi-number-font Fonts
  • --gwi-title-size, --gwi-title-weight, --gwi-sub-size Title and subtitle
  • --gwi-stat-size, --gwi-stat-label-size, --gwi-stats-cols, --gwi-stats-gap, --gwi-stat-bar-height Big numbers
  • --gwi-head-gap, --gwi-foot-gap, --gwi-max-width Spacing and width
  • --gwi-btn-radius, --gwi-btn-height Buttons
<gwi-chart
  type="bar"
  ranked=""
  unit="%"
  title="Styled inline with CSS variables"
